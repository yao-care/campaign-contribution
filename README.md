# 政治獻金指南

把整部政治獻金法，變成「我這個身分、這場選舉，能不能捐、能捐多少、什麼時候開始、事後怎麼報」的可查詢答案。

**自費製作的民間網站，與內政部、監察院、中央選舉委員會均無委託或合作關係。**

做的理由：政治獻金法條文不少，多數人真正要問的只有四件事——能不能捐、能捐多少、什麼時候可以開始收、事後怎麼申報。這些答案散在條文各處，官方網站沒有整理成可查詢的形式，所以做了一個補位。

站點聲明（立場、資料來源、選舉期間的自我約束）：[`/about/statement/`](https://campaign.yao.care/about/statement/)

設計依據見 [`docs/建站規格.md`](docs/建站規格.md)。該文件原以委辦案為前提撰寫，2026-08-30 已逐條修正，修正處均在原地註明。

## 現況

數字不寫在文件裡——寫進來的那一刻就開始過期，而讀的人無從得知它是什麼時候的。

```sh
npm run stat            # 法條、村里、政黨、行政區、申報統計、屆別、圖檔、頁數、依賴版本
npm run stat -- --json  # 同上，機器可讀
npm run check:links     # 站內連結數與斷鏈
```

頁面組成：法條、選舉類別、工具與預渲染結果、不得捐贈者、書表、名詞、問答、情境指南、
縣市、鄉鎮市區、村里、政黨，其餘為首頁與靜態頁。各項數量同上由指令取得。

## 技術

- **Astro**（版本見 `npm run stat`），`output: 'static'`，全站零執行 JS（只有資格檢核與站內搜尋兩頁有漸進增強腳本）
- 不裝任何前端追蹤、不使用 Cookie、不嵌入外部字型或腳本
- OKLCH 配色 + hex fallback，支援暗色模式；配色刻意避開藍、綠、白、橘等政黨識別色
- 最小字級 18px，色彩對比符合網站無障礙規範 110.07 的 AA

## 開始

```bash
npm install
npm run data        # 抓取外部資料（法條、村里、政黨）並產生資料集
npm run dev         # 開發（用 http://127.0.0.1:4321/，Astro 只綁 IPv4）
npm run build       # 抓資料 + 建置
npm run build:only  # 只建置，不重抓資料
```

`npm run fetch:parties` 需要本機安裝 Google Chrome——政黨資訊網的表格由瀏覽器端產生，直接抓 HTML 只會拿到表頭。

## 部署

GitHub Actions → GitHub Pages。推送到 `main` 自動建置並部署；另有每日排程重建，讓首頁與 `/countdown/` 的「距投票日 N 天」保持正確。

工作流程在 `.github/workflows/deploy.yml`，建置前會跑型別檢查與全站內部連結檢查，任一失敗就不部署。

外部資料預設使用 repo 內已提交的檔案，建置不依賴外部網站是否可用。要更新資料時，到 Actions 手動觸發並勾選 **重新抓取外部資料**。

### 網域

正式網域寫在 `src/site.mjs` 的 `DOMAIN` 常數，全站的 canonical、sitemap、robots、JSON-LD 與開放資料集網址都由此推導。

**換網域時要同時改兩個地方**，兩者必須一致，否則 GitHub Pages 會拒絕：

1. `src/site.mjs` 的 `DOMAIN`
2. `public/CNAME`

### DNS 設定

在 `yao.care` 的 DNS 服務商新增一筆 CNAME：

| 類型 | 名稱 | 值 | TTL |
|------|------|-----|-----|
| CNAME | `campaign` | `yao-care.github.io` | 自動或 3600 |

若使用 Cloudflare，**Proxy status 要設為 DNS only（灰雲）**，不要開橘雲。開了橘雲會讓 GitHub 無法簽發憑證，且 §10.1 的 managed robots.txt 與 Bot Fight Mode 會擋掉 AI 爬蟲。

設定後到 repo 的 Settings → Pages 確認 Custom domain 顯示 `campaign.yao.care`，並勾選 **Enforce HTTPS**（憑證簽發約需數分鐘到一小時）。

### 宣導素材

`npm run build:media` 以 HTML 模板加 headless Chrome 渲染出 PNG，沿用站上的 OKLCH token 與 18px 起跳字級，產出進版控。素材文案取自站上既有的法條資料與白話說明，不另編法律敘述。以 CC BY 4.0 釋出。

**影音不放在 GitHub Pages。** Pages 的站台上限 1 GB、頻寬每月 100 GB 軟上限；一支 10 MB 的影片播一萬次就用光整個月額度，而這個站的散播路徑是 LINE 群組，選前一週一萬次很正常。GitHub 對超量的處理建議直接寫「moving to a different hosting service」。因此影音只提供腳本與分鏡，真要放片建議另接 Cloudflare Stream 或 R2。

### GitHub Actions Secrets

| Secret | 用途 | 沒設定的後果 |
|--------|------|--------------|
| `INDEXNOW_KEY` | IndexNow 金鑰，用於選舉季當天通知搜尋引擎 | 建置正常，但不產生金鑰驗證檔、不提交 IndexNow |

金鑰是任意的 32 位十六進位字串，本機的在 `.env`。設定位置：Settings → Secrets and variables → Actions。

## 資料來源

| 資料 | 來源 | 取得方式 |
|------|------|----------|
| 政治獻金法全文 | 全國法規資料庫 | `scripts/fetch-law.mjs` |
| 村里清單 | 內政部戶政司 ODRP001 | `scripts/fetch-villages.mjs` |
| 現存政黨 | 內政部政黨資訊網 | `scripts/fetch-parties.mjs` |
| 收受起算日、書表 | 監察院陽光法令主題網 115/02/09 公告 | 人工核對後寫入資料層 |
| 申報收支統計 | 監察院政治獻金公開查閱平臺（第 21 條第 4 項法定公開資訊） | `scripts/fetch-donations.mjs` |

### 申報資料的處理原則

`scripts/fetch-donations.mjs` 取用監察院政治獻金公開查閱平臺的資料。該平臺依政治獻金法第 21 條第 4 項設立，平臺選單將三個下載專區歸類為「政府開放資料」，設立目的為「保障人民知的權利，增進人民對公共事務之瞭解、信賴及監督」。

監察院已於釋出前完成個資處理：個人捐贈者的身分證欄位為空、地址遮蔽至鄉鎮市區層級、聯絡電話為空；有值的統一編號為營利事業公開資訊。

本站在此之上再加一層限制：**`src/data/donations.json` 只保留聚合統計，不落地任何逐筆交易或個別捐贈者資料。** 頁面上呈現的是職位層級的收支結構，以及各政黨自行申報的年度數字；不做候選人之間的比較，也不做跨黨排行。

**法條原文一律以抓取結果為準。** 原文只從 `src/data/law.json` 來，渲染元件 `Statute.astro` 不接受任何自由文字參數——這讓「禁止改寫或憑記憶填寫法條」在架構上就成立，而不是靠寫作紀律。人工撰寫的白話說明放在 `src/content/law/*.md`，與原文並列且字體不同（原文襯線、說明黑體）。

## 已知的資料限制

內政部戶政司 ODRP001 有部分村里名使用**私用區（PUA）造字**碼位，例如「瓦□里」「磚□里」的第二字為 `U+FFFA8`。這些碼位在多數裝置與字型上顯示為豆腐字，正字須人工對照戶政司或內政部的正式公告後替換——`scripts/fetch-villages.mjs` 只會列出清單，不做推定。完整名單與數量：`npm run stat`。

另有村里名原本使用 CJK 相容表意文字（`U+2F85A`、`U+2F8EB`），抓取時已正規化為 NFC。不做這一步的話，網址與實際產出的檔案路徑會在 Linux 上對不起來，而 macOS 的檔案系統會自動正規化因此本機測不出來。`npm run check:links` 採嚴格字串比對，本機即可重現 Linux 的行為。

## 建站規格的四處勘誤

建置期間對照權威來源查出，已於程式碼修正，**請勿依規格改回**：

1. **§5.3 的起算日 8/25 有誤**。監察院 115/02/09 公告載明第 12 條第 4 款組（鄉鎮市民代表、直轄市山地原住民區民代表、村里長）為 **8 月 20 日**，因第 12 條第 3 項會把起始日提前至選舉公告發布之日。第 3 款組 4/25 與規格相符。
2. **§3.2 的 7,851 個村里是 10601 期別的數字**。ODRP001 較新的期別會回傳查無資料，抓取程序自動退回最新可用期別。目前採用的期別、村里與行政區筆數：`npm run stat`。
3. **§3.5 的 content collections 是 Astro 5 寫法**。Astro 7 已移除 `type: 'content'`，改用 `loader: glob()`，設定檔位置也改為 `src/content.config.ts`。
4. **§7 的 `--muted` 過不了 §11 的 AA**。原值 `#8a8f96` 在 `--alt`／`--mint` 灰底上僅 2.91:1，已加深至 4.52:1。

§5.4 要求複核的金額與期限（第 12、17、18、19、21 條）、§5.5 的 18 個會計項目，均已逐條對照原文，全部正確。

## 待外部確認

| 項目 | 影響 | 處理 |
|------|------|------|
| **網域未定** | robots／sitemap／canonical 目前指向 placeholder | 定案後改 `src/site.mjs` 一行 |
| **中選會 115 年選舉公告未發布** | 應選名額與選舉區從缺 | 公告後補齊，村里頁才能開放索引 |
| **村里戶籍人口無可用開放資料集** | 村里頁四個差異化欄位缺一 | 同上 |
| **白話說明尚未經法制單位審閱** | 全站署名為「本站編輯初稿（未經法制單位審閱）」 | 審閱後改為實際署名 |
| **機關宣導素材未提供** | `/downloads/` 與影音頁從缺 | 取得後補；PDF 素材須另做 HTML 版 |

依規格 §5.6，村里頁的四個差異化欄位（戶籍人口、本屆應選名額、上屆當選得票、起算日）未備齊者一律 `noindex` 且不列入 sitemap。目前全數如此，可正常瀏覽但不進搜尋索引。進索引的頁數見 `npm run stat`。

## 部署前必須確認

規格 §10.1 列的三個坑，會讓整套 GEO 歸零：

1. Cloudflare 會自動注入 managed robots.txt，預設把 GPTBot、ClaudeBot、Google-Extended 寫成 `Disallow: /`。要到後台**關掉這個功能**，不是在下面補 Allow 蓋過去。
2. Bot Fight Mode 與 WAF bot score 會在 robots 之外直接擋掉 AI 爬蟲且不留痕跡，須確認 AI Crawlers 設為放行。
3. 若採 `gov.tw` 子網域或機關代管，資安政策可能預設封鎖境外爬蟲。

## 法遵

- **不宣稱與機關的關係**：頁尾與[站點聲明](https://campaign.yao.care/about/statement/)明示無委託關係，不使用任何機關的識別標誌。預算法第 62 條之 1 規範的是政府機關編列預算辦理宣導，本站非委辦案，不適用。
- **競選期間的自我約束**：不涉候選人與政黨立場、不做跨黨比較、不呈現金額排行。村里頁的「上屆當選人姓名與得票」在中選會資料到位前一律從缺。這些不是法律要求本站做的，是自己訂的。
- **不轉載申報資料**：`/reports/` 僅提供監察院查閱管道導覽，不轉載申報內容，也不製作金額排行或比較。
- **政黨頁版型限制**：`/parties/` 只有制度事實欄位與該黨自行申報的數字，不做跨黨排行。版型限制比編輯守則可靠：沒有那個欄位，就寫不出那種內容。

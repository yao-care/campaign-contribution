## 0. 專案是什麼

**站名**：政治獻金指南
**目的**：把政治獻金法從 36 條法條，變成「我這個身分、這場選舉，能不能捐、能捐多少、什麼時候開始、事後怎麼報」的可查詢答案。
**規模**：8,442 頁靜態頁面。
**背景**：本站為自費製作的民間網站，與內政部、監察院、中央選舉委員會均無委託或合作關係。

> **2026-08-30 修正**：本文件原以「內政部 115 年度政治獻金法制網路宣導公開徵求案的替代提案」為前提撰寫，據此推導出委辦機關標示、機關提供素材、機關法制單位審稿等條文。實際上本站並非委辦案，那些前提不成立，相關條文已逐條修正並在原處註明。

**三種受眾，三條動線**：

| 受眾 | 搜尋行為 | 需要什麼 |
|------|----------|----------|
| 捐款人（個人／企業） | 「政治獻金 可以捐多少」「公司 捐政治獻金」 | 資格檢核、上限試算、抵稅 |
| 擬參選人與團隊 | 「里長 政治獻金 什麼時候開始收」「專戶怎麼申請」 | 起算日、專戶流程、書表、申報倒數 |
| 一般民眾 | 「XX里 里長」「政治獻金 罰則」 | 行政區頁、法制知識 |

## 1. 技術決策

| 項目 | 決定 | 理由 |
|------|------|------|
| 框架 | **Astro，static output** | 同一團隊的 folk.tw 已用 Astro 跑到 14,056 頁，路徑已驗證 |
| 後端 | **無** | 全部靜態產出 |
| 資料庫 | **無** | 建置期把外部資料轉成 JSON／content collections |
| 前端追蹤 | **不裝** | 頁面對使用者承諾「不收集資料」。referrer 與爬蟲行為改從伺服器日誌分析，同時省掉隱私政策與 Cookie 同意 |
| 互動 | 島嶼式（Astro islands），僅工具頁需要 | 其餘頁面零 JS |
| 部署 | 靜態託管 + CDN | TTFB 目標 < 500ms |

**硬性要求：所有答案必須存在於 HTML 中。** 工具頁的計算結果不能只在瀏覽器端算出來——AI 爬蟲多數不執行 JavaScript，答案在 JS 裡等於不存在。做法是為常見組合預先產生靜態結果頁（見 §5.4），前端互動只是加值。

## 3. 資料層

### 3.1 法條（全國法規資料庫）

來源：`https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0020049`

以下解析方式已實測可用（Python 版，移植成 Node 亦可）：

```python
import re, html, urllib.request

req = urllib.request.Request(
    "https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=D0020049",
    headers={"User-Agent": "Mozilla/5.0"})
s = urllib.request.urlopen(req).read().decode("utf-8")

blocks = re.split(r'<a[^>]*>第\s*(\d+(?:-\d+)?)\s*條</a>', s)
for i in range(1, len(blocks), 2):
    no   = blocks[i]
    body = blocks[i+1].split('<a ')[0]
    txt  = html.unescape(re.sub(r'<[^>]+>', '\n', body))
    txt  = '\n'.join(l.strip() for l in txt.split('\n') if l.strip())
    # → { article: no, text: txt }
```

實測結果：**36 條**（第 16 條為「（刪除）」，有效條文 35 條）。

**法條原文一律以抓取結果為準，禁止由模型改寫或憑記憶填寫。** 白話說明可以自己寫，但必須與原文並列呈現。

### 3.2 村里人口（內政部戶政司）

API：`https://www.ris.gov.tw/rs-opendata/api/v1/datastore/ODRP001/{yyymm}?page={n}`

- `yyymm` 為民國年月，例如 `10601`
- 分頁，每頁 2,000 筆，回應含 `totalPage` 與 `totalDataSize`
- **實測 106 年 1 月期別回傳 7,851 筆**，每筆一個村里
- 建站時要先試出最新可用期別（新期別可能尚未開放，逐月往前試）
- 欄位含 `site_id`（縣市＋鄉鎮市區）、村里名、出生死亡結婚離婚數

**頁數不要寫死 7,851**，以當期資料筆數為準。

### 3.3 選舉資料（中選會）

- 開放資料：`https://data.cec.gov.tw/`
- 選舉資料庫：`https://db.cec.gov.tw/`
- 需要的：歷屆村里長當選人與得票、本屆各行政區應選名額、選舉區劃分
- **本屆（115 年）應選名額須待中選會選舉公告發布後才有**，建置初期先以上屆資料佔位，並在頁面標示資料期別

### 3.4 政黨（內政部政黨資訊網）

`https://party.moi.gov.tw/` — 站上統計顯示現存政黨 **80**（另有廢止備案 229、自行解散 86、撤銷備案 2）。

### 3.5 Content Collections schema

```ts
// src/content/config.ts
import { defineCollection, z } from 'astro:content';

const law = defineCollection({
  type: 'content',
  schema: z.object({
    article: z.number(),              // 條號
    title: z.string(),                // 一句話主題
    conclusion: z.string(),           // 40–60 字結論段
    originalText: z.string(),         // 法條原文，抓取而來
    repealed: z.boolean().default(false),
    relatedTool: z.string().optional(),   // 掛哪個工具
    relatedArticles: z.array(z.number()).default([]),
    updated: z.date(),
    reviewer: z.string(),             // 審閱者署名
  }),
});

const donors = defineCollection({
  type: 'content',
  schema: z.object({
    clause: z.number(),               // 第 7 條第幾款
    target: z.string(),               // 對象名稱
    verifyAgency: z.array(z.string()), // 查證機關
    conclusion: z.string(),
    updated: z.date(),
  }),
});

const elections = defineCollection({
  type: 'content',
  schema: z.object({
    slug: z.string(),
    position: z.string(),             // 職位名稱
    clause12: z.number(),             // 第 12 條第幾款
    startOffsetMonths: z.number(),    // 任期屆滿前幾個月
    partyDonationCap: z.number(),     // 第 18 條第 2 項上限（元）
    updated: z.date(),
  }),
});

// glossary / faq / forms / guides 依相同模式定義
```

### 5.4 預渲染答案頁 36 頁

| 工具 | 組合 | 頁數 | 依據 |
|------|------|------|------|
| 起算日 `/tools/timeline/{職位}/` | 11 種職位 | 11 | 第 12 條 |
| 上限試算 `/tools/limit/{捐贈者}-to-{對象}/` | 個人／營利事業／人民團體 × 政黨／擬參選人 = 6；政黨對推薦候選人 6 級 | 12 | 第 17、18 條 |
| 罰則對照 `/tools/penalty/{條號}/` | 第 25–32 條 | 8 | 第 25–32 條 |
| 申報期限 `/tools/deadline/{身分}/` | 政黨／政治團體／擬參選人 | 3 | 第 21 條 |
| 抵稅試算 `/tools/deduction/{身分}/` | 個人／營利事業 | 2 | 第 19 條 |

**捐贈上限數字**（建置時務必對照法條原文複核）：

- 對同一政黨或政治團體，每年：個人 30 萬／營利事業 300 萬／人民團體 200 萬
- 對不同政黨或政治團體，每年合計：個人 60 萬／營利事業 600 萬／人民團體 400 萬
- 對同一（組）擬參選人，每年：個人 10 萬／營利事業 100 萬／人民團體 50 萬
- 對不同擬參選人，每年合計：個人 30 萬／營利事業 200 萬／人民團體 100 萬
- 扣除額：個人不逾綜合所得總額 20%，且總額上限 20 萬；營利事業不逾所得額 10%，且上限 50 萬
- 申報期限：政黨與政治團體於年度結束後 5 個月內；擬參選人於投票日後 3 個月內；擬參選人收受達 1,000 萬元者，應於投票日後 70 日內委託會計師查核簽證

## 6. 七種頁面模板

所有頁面共用同一條頂欄與麵包屑。每頁最上方先給結論，理由與法條在下方。手機優先，單欄。

### T1 首頁 `/`
三個入口（我要捐款／我要參選／我想查）＋ 選舉倒數 ＋ 最多人查的問題（連往法條頁）。不做一鍋端的法規總覽。

### T2 村里頁 `/villages/{縣市}/{區}/{村里}/`
上半四個數字逐里不同（人口、應選名額、上屆得票、起算日）→ 起算日提醒框 → 「在某某里，誰可以捐、可以捐多少」→ 底部同區其他里連結（形成區內內鏈網）。

### T3 鄉鎮市區索引 `/regions/{縣市}/{區}/`
統計列（里數、應選席次、改選職位數）→ 本區要選的職位與各自起算日 → 轄下村里清單附人口。這 368 頁是爬蟲進入 7,851 個村里頁的入口，沒有它村里頁會是孤島。

### T4 法條頁 `/law/{條號}/`
一句話結論 → 法條原文（**襯線體、灰底、朱線標示**）→ 逐款拆解 → 掛對應工具。原文與白話的字體必須不同，讓讀者分得出哪句是法律、哪句是本站詮釋。

### T5 工具頁 `/tools/{工具}/`
逐題式，每答一題就顯示中間結果。結論放最上面用最大的字，法條依據放結論下方。純前端計算、不收集資料，但**必須有預渲染的靜態版本**。

### T6 選舉類別頁 `/elections/{職位}/`
統計列（起算日、截止日、個人上限、全國該職位數）→ 收受期間 → 誰可以捐與上限 → 各縣市分佈。這是工具頁的可索引靜態版本，也是村里層與縣市層之間的橫向樞紐。

### T7 政黨頁 `/parties/{政黨}/`
只有制度事實欄位，**沒有金額排行、沒有敘述性段落**，並在頁面明說不做評論、不做比較。版型限制比編輯守則可靠——沒有那個欄位，就寫不出那種內容。

## 9. AEO 實作

### 9.1 五條寫作規則

1. **H2 一律寫成完整問句**。「村里長什麼時候可以開始收政治獻金？」不是「收受期間」。
2. **問句下方第一段就是答案，40–60 字，獨立成句**。不用「這個」「上述」開頭——會被單獨摘走。
3. **數字一律進表格**，不要寫成句子。
4. **每頁頂部三行「本頁重點」**，每行是可單獨成立的事實句。
5. **每頁標更新日期與資料來源**。法規內容沒有日期不會被引用。

### 9.2 chunk 友善

- 一個 H2 底下 150–400 字，能獨立成立
- 不跨標題依賴
- 每個 H2 第一句就是該段結論
- 數字用真 `<table>` 加 `<th>`，不用 div 模擬
- 名詞頁用 `<dl>`
- 一頁一個 H1，標題階層不跳級

### 9.3 每頁固定三區塊

| 區塊 | 位置 | 規格 |
|------|------|------|
| 本頁重點 | H1 正下方 | 三行事實句，含具體數字或日期 |
| 資料來源與更新日 | 內容結束後 | 法條連結、出處、更新日期、審閱者 |
| 接下來會問什麼 | 頁尾 | 3–5 條後續問題連結 |

### 9.4 結構化資料

| 頁面 | 型別 | 關鍵欄位 | 備註 |
|------|------|----------|------|
| 法條頁 | `Legislation` | `legislationIdentifier`、`legislationJurisdiction: TW`、`legislationType`、`isPartOf` | 無複合式結果，但這是 AI 引擎判斷「這是法條原文」最直接的訊號 |
| FAQ 頁 | `FAQPage` | `Question` / `acceptedAnswer` | Google 2023-08 起僅對權威政府與健康網站顯示複合式結果；本案由機關掛名故值得做，但判定權在 Google |
| 書表頁 | **不要用 `HowTo`** | 改用 `Article` + 有序步驟標記 | HowTo 複合式結果已停止顯示、官方文件下架 |
| 村里／區頁 | `Place` + `BreadcrumbList` | `containedInPlace` 串起縣市 › 區 › 里 | 麵包屑會顯示 |
| 政黨頁 | `Organization` | `foundingDate`、`identifier` | schema.org 無政黨專屬型別 |
| 工具頁 | `WebPage` + `SoftwareApplication` | — | 讓 AI 引擎理解這頁能算什麼 |
| 全站 | `Organization` + `WebSite` | `publisher`、`sameAs` | E-E-A-T 基礎 |

## 10. GEO 實作

### 10.1 robots.txt（已定案：可檢索、可引用、可進訓練集）

```
User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=yes
Allow: /
Disallow: /search
Disallow: /admin/

Sitemap: https://{domain}/sitemap-index.xml
```

**不要逐一列 AI 爬蟲的 user-agent**——列了只會製造衝突。

三個會踩到的坑：

1. **Cloudflare 會自動注入 managed robots.txt**，預設把 GPTBot、ClaudeBot、Google-Extended 等寫成 `Disallow: /`。要到後台**關掉這個功能**，不是在下面補一段 Allow 蓋過去（同團隊的 appi.news 現在正是兩組規則打架的狀態）。
2. **Bot Fight Mode 與 WAF bot score** 會在 robots 之外直接擋掉 AI 爬蟲且不留痕跡。要確認 AI Crawlers 設定為放行。
3. 若採 `gov.tw` 子網域或機關代管，**資安政策可能預設封鎖境外爬蟲**——這會讓整套 GEO 歸零，必須在開工前確認。

### 10.2 技術硬條件

- 全站伺服器端渲染／靜態產出，**答案必須在 HTML 裡**
- TTFB < 500ms（即時取用型爬蟲耐心短）
- 不要 Cookie 牆或同意彈窗擋住內容
- 事實不要藏在 PDF、圖片、iframe。**2026-08-30 修正**：原文假設機關會提供 PDF 素材。本站無機關素材來源，改為自製素材，且每張圖都有獨立的 HTML 頁面承載完整文字，圖片本身不是唯一載體

### 10.3 可引用單元約 181 個

36 預渲染 + 60 FAQ + 35 名詞 + 36 法條結論句 + 12 對照表。加上 8,241 個行政區頁的在地問答（模板生成）。

### 10.4 開放資料集

輸出 CSV 與 JSON 到 `/public/data/`，掛 `Dataset` schema：
- 四款職位的起算日與截止日對照
- 三種捐贈者 × 兩種受贈對象的上限矩陣
- 全國村里選舉基本資料
- 第 7 條 11 款不得捐贈者對照

資料集是引用磁鐵。機關掛名的話可再上架政府資料開放平臺。

### 10.5 llms.txt

根目錄放一份 markdown 索引。這是社群慣例，主要 AI 供應商尚未正式承諾支援。成本一個檔案，做了不虧，但不列入關鍵路徑。

## 11. 無障礙（硬性驗收條件）

現行規範為數位發展部**「網站無障礙規範（110.07）」**，取代舊的 2.0 版。分 A／AA／AAA 三級，13 指引、78 條成功準則，標章效期 3 年。機關委託網站契約通常要求 **AA**。

**必須從第一天就照規範寫**，8,442 頁事後回頭改是不可能的：

- 所有互動可鍵盤操作，焦點狀態可見
- 色彩對比達 AA（一般文字 4.5:1、大型文字 3:1）
- 表格用 `<th>` 與 `scope`
- 圖片有替代文字；純裝飾圖 `alt=""`
- 表單標籤與錯誤訊息可被輔助技術讀取
- 工具頁的逐題互動最容易失分，優先檢測

## 12. 內容紅線

1. **不要用 AI 大量生成法規解釋。** 條文數字生成錯誤是實質損害，而且掛著機關名字。所有法條內容以抓取的原文為準、人工核對、留審閱署名。
2. **不要為了覆蓋問句而製造重複頁。** 問法變體寫在同一頁裡面。
3. **不要宣稱與機關的關係超出實際。** **2026-08-30 修正**：本站與任何機關都沒有委託或合作關係，這一點在頁尾與站點聲明頁明示。不使用機關識別標誌、不暗示官方背書。
4. **競選活動期間的限制須經機關法制單位確認。** 各級機關於競選活動期間不得從事與競選宣傳有關之活動；村里頁的「上屆當選人姓名與得票」、政黨頁在機關掛名下呈現，界線由甲方認定。最壞情況是競選期間隱藏候選人相關欄位，替代欄位已於 §5.6 備妥。
5. ~~**預算法第 62 條之 1**：政府機關編列預算於網路媒體辦理宣導，應明確標示為廣告並揭示辦理機關。~~
   **2026-08-30 修正：本條不適用。** 本站非委辦案，未接受機關委託、未動用政府預算，預算法第 62 條之 1 規範的是政府機關編列預算辦理宣導的情形，與本站無涉。頁尾改為標示民間自製與無委託關係。
